# FixMyRide – Landing Page

Sri Lanka roadside-assistance concept: a responsive one-page landing site (HTML, CSS, JavaScript) built by a 5-member team.

## Project structure

```
FixMyRide/
├── index.html            
├── css/
│   ├── base.css          
│   ├── hero.css          
│   ├── features.css      
│   ├── gallery-team.css  
│   └── form-footer.css   
├── js/
│   ├── nav.js            
│   ├── splash.js         
│   ├── animations.js     
│   └── form.js           
└── images/               
```

## Run locally

Open `index.html` in a browser (or use VS Code "Live Server").

## Deploy (GitHub Pages)

Repo → Settings → Pages → Branch `main` / root. For a custom domain add a `CNAME` file containing the domain.
