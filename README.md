# FixMyRide – Landing Page

Sri Lanka roadside-assistance concept: a responsive one-page landing site (HTML, CSS, JavaScript) built by a 5-member team.

## Project structure

```
FixMyRide/
├── index.html            
├── css/
│   ├── base.css          
│   ├── hero.css          
│   ├── features.css

│   ├── splash.js         
│   ├── animations.js     
│   └── form.js           
└── images/               
```
